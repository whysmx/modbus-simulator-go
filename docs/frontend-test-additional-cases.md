## 测试方法论改进建议

### 1. 测试覆盖矩阵
需要为每个操作验证以下状态:

| 操作 | 设备树状态 | 标签页状态 | 数据缓存 |
|------|-----------|-----------|---------|
| 创建连接 | ✅ 必须验证 | ⚠️ 可能影响 | ⚠️ 可能影响 |
| 创建从站 | ✅ 必须验证 | ⚠️ 可能影响 | ⚠️ 可能影响 |
| 创建寄存器 | ✅ 必须验证 | ✅ 必须验证 | ✅ 必须验证 |
| 编辑操作 | ✅ 必须验证 | ⚠️ 可能影响 | ✅ 必须验证 |
| 删除操作 | ✅ 必须验证 | ✅ 必须验证 | ✅ 必须验证 |

### 2. 测试流程优化
**原流程**:
1. 测试功能是否工作
2. 验证操作结果
3. ❌ **遗漏**: 验证副作用(状态改变)

**改进流程**:
1. 测试功能是否工作
2. 验证操作结果
3. ✅ **新增**: 验证所有相关状态(树、标签页、缓存)
4. ✅ **新增**: 验证连续操作的累积效应

### 3. 自动化测试建议
建议添加 Playwright 自动化测试覆盖以下场景:

```javascript
// 示例: 测试创建寄存器后设备树状态保持
test('设备树状态在创建寄存器后保持', async ({ page }) => {
  // 1. 展开连接和从站
  await page.click('[data-type="connection"]');
  await page.click('[data-type="slave"]');

  // 2. 打开寄存器标签页
  await page.click('text=保持寄存器');

  // 3. 创建寄存器
  await page.click('button:has-text("添加寄存器")');
  await page.fill('#regStartAddr', '40001');
  await page.fill('#regHexData', '0064');
  await page.click('button:has-text("保存")');

  // 4. 验证设备树状态 (关键!)
  await expect(page.locator('[data-type="connection"] .tree-expand')).toHaveText('▼');
  await expect(page.locator('[data-type="slave"] .tree-expand')).toHaveText('▼');
});
```
