## API 接口参考

### 连接接口

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/connections/tree` | 获取设备树 |
| POST | `/api/connections` | 创建连接 |
| PUT | `/api/connections/{connId}` | 更新连接 |
| DELETE | `/api/connections/{connId}` | 删除连接 |

### 从站接口

| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/api/connections/{connId}/slaves` | 创建从站 |
| PUT | `/api/connections/{connId}/slaves/{slaveId}` | 更新从站 |
| DELETE | `/api/connections/{connId}/slaves/{slaveId}` | 删除从站 |

### 寄存器接口

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/connections/{connId}/slaves/{slaveId}/registers` | 获取寄存器 |
| POST | `/api/connections/{connId}/slaves/{slaveId}/registers` | 创建寄存器 |
| PUT | `/api/connections/{connId}/slaves/{slaveId}/registers/{regId}` | 更新寄存器 |
| DELETE | `/api/connections/{connId}/slaves/{slaveId}/registers/{regId}` | 删除寄存器 |

## 寄存器类型参考

| 类型 | 地址范围 | 功能码 | 可写 |
|------|----------|--------|------|
| Coils | 1-9999 | FC01 | 是 |
| Discrete Inputs | 10001-19999 | FC02 | 否 |
| Input Registers | 30001-39999 | FC04 | 否 |
| Holding Registers | 40001-49999 | FC03 | 是 |
