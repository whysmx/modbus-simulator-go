## 🐛 Bug 修复 (BUG-005)

### 问题描述

**用户反馈**: "点击添加寄存器后,数据就消失了"

**根本原因**:
- `loadTree()` 每次都完全重新渲染设备树
- 没有保存和恢复展开/折叠状态
- 用户需要手动重新展开节点

### 修复方案

实现 `expandedNodes` Set 来跟踪展开状态:

```javascript
// 1. 添加状态跟踪
let expandedNodes = new Set();

// 2. 渲染时检查并恢复状态
const isExpanded = expandedNodes.has(nodeId);
el.innerHTML = `<div class="${isExpanded ? '' : 'collapsed'}">...</div>`;

// 3. 切换时保存状态
function toggleNode(el, nodeId) {
    if (展开) {
        expandedNodes.add(nodeId);
    } else {
        expandedNodes.delete(nodeId);
    }
}
```

### 修复效果

- ✅ 创建连接后,设备树保持展开
- ✅ 创建从站后,设备树保持展开
- ✅ 创建寄存器后,设备树保持展开
- ✅ 编辑操作后,设备树保持展开
- ✅ 删除操作后,设备树保持展开

### 1. 测试覆盖的重要性

**问题**: 测试清单有 T5.5,但测试结果中缺失

**教训**:
- ✅ 测试清单 ≠ 测试执行
- ✅ 需要自动化测试确保覆盖
- ✅ 定期review测试完整性

### 2. 功能测试 vs 状态测试

**问题**: 只验证"操作成功",忽略了"副作用"

**改进**:
```javascript
// 原测试流程
操作 → 验证结果 → ❌ 忘记验证状态

// 改进后流程
操作 → 验证结果 → ✅ 验证所有相关状态
```

**发现过程**:
1. 用户:"点击添加寄存器后,数据消失"
2. 我们用 Playwright 复现
3. 发现是状态丢失,不是数据丢失
4. 定位并修复bug
