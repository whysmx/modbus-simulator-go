# 架构设计 | 总纲

## 项目概览

**项目名称**: Modbus 仿真器
**开发语言**: Go
**部署方式**: 本地部署，单一可执行文件

## 技术栈

### 后端技术
- **Go 1.22+**: 后端语言，原生支持并发和跨平台编译
- **net/http**: 标准库 HTTP 服务
- **embed**: 嵌入静态资源，实现单文件部署
- **内存存储**: 纯内存数据存储，无外部依赖

### 前端技术
- **HTML/CSS/JavaScript**: 原生前端，无框架依赖
- **嵌入式部署**: 静态文件编译进二进制

### 协议支持
- **Modbus TCP**: 标准以太网 Modbus 协议
- **Modbus RTU over TCP**: TCP 封装的 RTU 协议

## 系统架构

### 整体架构图
```
┌─────────────────────────────────────┐
│              前端层                  │
│       HTML + CSS + JavaScript       │
│         (嵌入式静态文件)              │
└─────────────────┬───────────────────┘
                  │ HTTP API
┌─────────────────┴───────────────────┐
│              后端层                  │
│           Go HTTP Server            │
├─────────────────────────────────────┤
│           业务服务层                  │
│ ConnectionService | ModbusService   │
│   SlaveService | RegisterService    │
├─────────────────────────────────────┤
│           数据存储层                  │
│          In-Memory Store            │
└─────────────────┬───────────────────┘
                  │
┌─────────────────┴───────────────────┐
│            TCP服务层                 │
│      Modbus协议仿真服务              │
└─────────────────────────────────────┘
```

### 数据流架构
```
Web前端 ←→ HTTP API ←→ 业务服务 ←→ 内存存储
                          ↓
                   TCP服务 ←→ Modbus客户端
```

## 核心模块

### 1. Web前端
- **设备树管理**: 分层展示连接、从机、寄存器
- **配置界面**: 可视化配置管理
- **数据管理**: 寄存器数据编辑和展示

### 2. HTTP API
- **RESTful接口**: 标准 REST API 设计
- **CRUD操作**: 连接、从机、寄存器管理
- **数据验证**: 请求参数校验和错误处理

### 3. TCP服务
- **多端口监听**: 支持同时监听多个端口
- **自动端口分配**: 新增连接时自动分配端口（从502开始递增）
- **协议仿真**: 实现 Modbus 读操作（功能码01-04），不支持写操作
- **并发处理**: 支持多客户端同时连接

### 4. 数据层
- **三层数据结构**: connections → slaves → registers
- **内存存储**: 使用 sync.RWMutex 保证并发安全
- **无持久化**: 重启后数据丢失

## 部署架构

### 开发环境
```bash
# 编译
go build -o modbus-simulator ./cmd/modbus-simulator

# 运行
./modbus-simulator

# 访问 http://localhost:8080
```

### 生产部署
- **单文件**: 编译后为单一可执行文件
- **零依赖**: 无需安装任何运行时
- **跨平台**: 支持 Linux, macOS, Windows

## 关键特性

### 轻量化
- 单二进制文件 < 20MB
- 内存占用 < 50MB
- 启动时间 < 1秒

### 易部署性
- 单文件部署
- 零配置启动
- 跨平台支持

### 可扩展性
- 模块化服务架构
- 清晰的接口定义
- 易于添加新功能码

## 总结

整个系统采用嵌入式前端 + Go 后端的单体架构，后端专注于 API 服务和协议仿真，前端通过嵌入方式打包进二进制。通过轻量级技术栈和模块化设计，实现了高性能、易部署、零依赖的 Modbus 仿真解决方案。
