## 发现的问题

| 问题编号 | 描述 | 严重程度 | 状态 |
|----------|------|----------|------|
| BUG-001 | 静态文件路由问题：/static/ 前缀未正确处理 | 严重 | ✅ 已修复 |
| BUG-002 | T2.3.3: 删除连接后相关标签页未自动关闭 | 中等 | ✅ 已修复 |
| BUG-003 | T2.1.3: 提交空表单无明显错误提示 | 低 | ✅ 已修复 (添加alert提示) |
| BUG-004 | T5.4: 无右键菜单功能 | 低 | ✅ 已解决 (使用内联按钮设计) |
| BUG-005 | T5.5: 设备树状态不持久化 | 中等 | ✅ 已修复 (2026-01-26) |

**BUG-005 详情**:
- **问题**: 创建/编辑/删除连接、从站或寄存器后,设备树自动折叠,用户需要手动重新展开
- **根本原因**: `loadTree()` 每次都重新渲染整个树,没有保存和恢复展开状态
- **解决方案**: 实现 `expandedNodes` Set 来跟踪展开的节点,在渲染时恢复状态
- **影响**: 用户体验差,需要反复展开节点
- **修复时间**: 2026-01-26
- **修复文件**: `internal/web/static/js/app.js`
