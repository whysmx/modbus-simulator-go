# 数据模型设计

## 概述

本项目使用纯内存存储，数据模型使用 Go struct 定义。重启后数据丢失。

## 数据模型

### 协议类型

```go
// ProtocolType 定义 Modbus 协议变体
type ProtocolType int

const (
    ModbusRtuOverTcp ProtocolType = 0  // Modbus RTU Over TCP（默认）
    ModbusTcp        ProtocolType = 1  // Modbus TCP
)
```

### Connection（连接配置）

```go
// Connection 表示一个 TCP 端口绑定的 Modbus 连接
type Connection struct {
    ID           string       `json:"id"`           // 32位无横杠UUID
    Name         string       `json:"name"`         // 连接名称（唯一）
    Port         int          `json:"port"`         // 端口号（自动分配，从502开始递增）
    ProtocolType ProtocolType `json:"protocolType"` // 协议类型：0=RTU over TCP, 1=TCP
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| ID | string | 32位无横杠UUID，主键 |
| Name | string | 连接名称，唯一 |
| Port | int | 端口号，新增时自动分配（从502开始递增），唯一 |
| ProtocolType | int | 协议类型：0=Modbus RTU Over TCP（默认），1=Modbus TCP |

### Slave（从机配置）

```go
// Slave 表示一个 Modbus 从机设备
type Slave struct {
    ID      string `json:"id"`      // 32位无横杠UUID
    ConnID  string `json:"connId"`  // 所属连接ID
    Name    string `json:"name"`    // 从机名称
    SlaveID int    `json:"slaveId"` // 从机地址（1-247）
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| ID | string | 32位无横杠UUID，主键 |
| ConnID | string | 所属连接ID，外键 |
| Name | string | 从机名称，同连接下唯一 |
| SlaveID | int | 从机地址（1-247），同连接下唯一 |

### Register（寄存器配置）

```go
// Register 表示一组连续的 Modbus 寄存器
type Register struct {
    ID           string `json:"id"`           // 32位无横杠UUID
    SlaveID      string `json:"slaveId"`      // 所属从机ID
    StartAddr    int    `json:"startAddr"`    // 起始逻辑地址
    HexData      string `json:"hexData"`      // 连续寄存器的16进制字符串
    Names        string `json:"names"`        // 逗号分隔的寄存器名称（可选）
    Coefficients string `json:"coefficients"` // 逗号分隔的显示系数（可选）
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| ID | string | 32位无横杠UUID，主键 |
| SlaveID | string | 所属从机ID，外键 |
| StartAddr | int | 起始逻辑地址，同从机下唯一 |
| HexData | string | 连续寄存器的16进制字符串（大写、无0x前缀） |
| Names | string | 逗号分隔的寄存器名称（可选，用于前端显示） |
| Coefficients | string | 逗号分隔的显示系数（可选，默认1.0） |

### RegisterType（寄存器类型）

```go
// RegisterType 定义 Modbus 寄存器类型
type RegisterType int

const (
    Coil            RegisterType = iota // 功能码 01, 地址 00001-09999
    DiscreteInput                       // 功能码 02, 地址 10001-19999
    InputRegister                       // 功能码 04, 地址 30001-39999
    HoldingRegister                     // 功能码 03, 地址 40001-49999
)
```

| 类型 | 功能码 | 地址范围 | 数据格式 |
|------|--------|----------|----------|
| Coil（线圈） | 01 | 00001-09999 | 位型，每2个hex=1字节=8位 |
| DiscreteInput（离散输入） | 02 | 10001-19999 | 位型，每2个hex=1字节=8位 |
| InputRegister（输入寄存器） | 04 | 30001-39999 | 寄存器型，每4个hex=1个16位寄存器 |
| HoldingRegister（保持寄存器） | 03 | 40001-49999 | 寄存器型，每4个hex=1个16位寄存器 |

## 数据关系

```
Connection (1) ──→ (N) Slave (1) ──→ (N) Register
```

- 删除 Connection 时级联删除其下所有 Slave
- 删除 Slave 时级联删除其下所有 Register

## HexData 字段说明

### 寄存器型（FC03/04）
- 长度为4的倍数
- 每4个十六进制字符 = 1个16位寄存器
- 示例：`"01020304"` = 2个寄存器：0x0102, 0x0304

### 位型（FC01/02）
- 长度为2的倍数
- 每2个十六进制字符 = 1字节 = 8位
- 示例：`"FF00"` = 2字节 = 16位

## Names 和 Coefficients 字段说明

### Names 字段
- 逗号分隔的字符串，对应 HexData 中每个寄存器的显示名称
- 示例：`"Temperature,Humidity,Pressure"` 或 `"温度,,压力"`（中间空名称使用空字符串）
- 可为空字符串，表示不使用自定义名称

### Coefficients 字段
- 逗号分隔的数字字符串，对应每个寄存器的显示系数
- 示例：`"0.1,1.0,0.01"` 或 `"0.1,,2.0"`（空位置默认为1.0）
- 可为空字符串，表示所有系数默认为1.0

### 使用示例

```go
register := Register{
    ID:           "abc123",
    SlaveID:      "slave001",
    StartAddr:    40001,
    HexData:      "01020304",           // 2个寄存器：0x0102=258, 0x0304=772
    Names:        "Temperature,Humidity",
    Coefficients: "0.1,0.01",
}

// 前端显示效果：
// 寄存器40001: Temperature = 258 * 0.1 = 25.8
// 寄存器40002: Humidity = 772 * 0.01 = 7.72
```

## 内存存储结构

```go
// Store 内存存储结构
type Store struct {
    mu          sync.RWMutex
    connections map[string]*Connection  // key: Connection.ID
    slaves      map[string]*Slave       // key: Slave.ID
    registers   map[string]*Register    // key: Register.ID
}
```

### 索引关系
- `connections`: 按 ID 索引所有连接
- `slaves`: 按 ID 索引所有从机
- `registers`: 按 ID 索引所有寄存器

### 查询优化
- 查询某连接下的从机：遍历 slaves，筛选 ConnID
- 查询某从机下的寄存器：遍历 registers，筛选 SlaveID
- 按地址查询寄存器：遍历 registers，筛选 SlaveID + StartAddr 范围
